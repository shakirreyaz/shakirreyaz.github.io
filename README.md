# Shakir Reyaz Portfolio

A responsive static portfolio website built from Shakir Reyaz's CV.

## Files
- `index.html` — portfolio content
- `style.css` — responsive design
- `script.js` — mobile menu + current year

## Publish on GitHub Pages
1. Create a repository named `YOUR_GITHUB_USERNAME.github.io`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch** → `main` → `/ (root)`.
5. Your website will be available at `https://YOUR_GITHUB_USERNAME.github.io`.

## Before publishing
Search `index.html` for `add profile URL` and replace the placeholder `#` links with your real GitHub and LinkedIn URLs.
